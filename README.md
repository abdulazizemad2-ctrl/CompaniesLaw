# بنك أسئلة الشركات

اختبار تفاعلي في قانون الشركات (الجزء الأول): 195 سؤالاً، منها أسئلة من التجميعات السابقة وأسئلة جديدة تغطي الملخص.

يختار الطالب نوع الأسئلة (اختيار من متعدد، صح وخطأ، حالات تطبيقية)، ومصدرها، وموضوعها، وعددها، وطريقة التصحيح.

الموقع صفحة واحدة: `index.html`، ويعمل بفتحه مباشرة في المتصفح أو عبر GitHub Pages.
